STUDENT MANAGEMENT SYSTEM 

Tech Stack used :-

•Core Java.

•Swing for GUI.

•File Handling using FileWriter and BufferedReader.

•Exception Handling.

The Student Grade Management System is a simple Java-based desktop application built using Core Java and Swing. It allows users to enter student details such as name, ID, and marks for three subjects. The system calculates the total, percentage, and grade automatically based on the entered marks. All records are saved in a text file using Java's file handling, and users can also view all saved student data through the GUI.
